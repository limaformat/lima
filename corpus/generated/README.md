# Generated boundary cases

This directory is reserved for generator-produced conformance cases (large
scalars, deep nesting, resource-limit boundaries — see
[`docs/corpus-design/README.md`](../../docs/corpus-design/README.md), §9).

Currently empty: the example generator case
([`core/scalar-limit-above.json`](../core/scalar-limit-above.json)) lives
under `corpus/core/` instead, since it is small enough to review directly.
Once the loader and generators exist, larger generated cases belong here.
