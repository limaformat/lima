# lima

**LIMA Is Metadata Annotation** — a small, predictable frontmatter format.

> ⚠️ This crate is a placeholder. The Rust implementation itself has not
> been written yet — the specifications and conformance corpus it will be
> checked against are both finished.
>
> Specification: https://limaformat.dev
> Progress: https://github.com/limaformat/lima

## Status

- [x] Lima Core 1.0 specification — complete
- [x] Lima References 1.0 specification — complete
- [x] Conformance test corpus — 250 cases, both specs, shared with the
      TypeScript implementation (`corpus/` in the repository root)
- [ ] Rust implementation — not started

A working, published implementation exists today in TypeScript:
[`@limaformat/lima`](https://www.npmjs.com/package/@limaformat/lima)
([source](https://github.com/limaformat/lima/tree/main/js)).

Watch the repository for updates.
