## Maintaining these instructions

`AGENTS.md` is the single shared source of truth for project instructions.

- Add, change, or remove general rules, workflows, and conventions only in
  `AGENTS.md`.
- Do not expand `CLAUDE.md` into a second rule source.
- Do not copy existing shared rules from `AGENTS.md` into this file.
- For a change request to project instructions, edit `AGENTS.md` by default.
- Add Claude-specific notes here only if they apply exclusively to Claude
  Code and would be unsuitable for other tools.
